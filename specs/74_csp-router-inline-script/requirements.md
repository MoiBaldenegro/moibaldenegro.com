# Requisitos — Navegaciones del ClientRouter sin violación de CSP por el script data: del router (feature 74 csp-router-inline-script)
# Prioridad baja por decisión humana («ponla hasta el final, no es importante»); depends_on [73] para quedar al final del backlog.
# Causa (progress/research/horizontal_feedback.md §3): node_modules/astro/dist/transitions/router.js:110 inserta <script type="module" src="data:application/javascript,"> cuando el último script module pendiente del documento nuevo es inline; la CSP obligatoria de REQ-64-11 no permite data: en script-src.
# ENMIENDA (2026-10-09, horizontal_feedback.md §6): assetsInlineLimit (REQ-74-01/02/04, ya implementado con su test) elimina la violación al entrar en los posts, pero no al VOLVER a la portada: el router salta los scripts ya ejecutados y el último módulo pendiente es el cargador inline de la server island de HTB (siempre inline). Decisión humana: «sobre la 74 vamos a permitirlo, opción A» = data: solo en una directiva script-src-elem nueva.
#   REQ-74-03 sustituye a REQ-64-11 como política vigente (antes exigía la CSP sin cambios). REQ-74-07 pasa de condición de parada a invariante de script-src. REQ-74-10..15 son nuevos.
#   script-src-elem sustituye a script-src para los elementos <script>, por eso repite todos sus orígenes. script-src queda igual: sigue rigiendo atributos de evento (script-src-attr no se declara y hereda de script-src) y eval (sin 'unsafe-eval'); worker-src hereda de script-src y no recibe data:.

## Requisitos

REQ-74-01 El archivo astro.config.mjs SHALL declarar vite.build.assetsInlineLimit como función que devuelve false para los chunks de script de componentes Astro y undefined para el resto de assets.
REQ-74-02 WHEN se construye el sitio, el último elemento script de tipo module de cada HTML del build SHALL tener atributo src.
REQ-74-03 La política Content-Security-Policy vigente que sustituye a REQ-64-11 en src/domain/http/security-headers.ts y public/_headers SHALL valer default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline' https://static.cloudflareinsights.com; script-src-elem 'self' 'unsafe-inline' https://static.cloudflareinsights.com data:; connect-src 'self' https://cloudflareinsights.com; frame-src https://www.youtube-nocookie.com https://www.youtube.com; frame-ancestors 'none'; base-uri 'self'; object-src 'none'.
REQ-74-04 WHEN se construye el sitio, los HTML de los posts SHALL referenciar el script de code-copy como chunk externo bajo /_astro/ en lugar de un script module inline.
REQ-74-05 WHEN el usuario navega con el ClientRouter mediante clics reales por portada y post con bloque de código y portada y /about y /search y post con vídeo sobre astro preview con la CSP de REQ-74-03, el navegador SHALL registrar cero violaciones de CSP en cada paso incluida la vuelta a la portada.
REQ-74-06 WHEN el ClientRouter termina de navegar a un post con bloque de código, la página SHALL disparar astro:page-load y mostrar el botón Copiar funcional.
REQ-74-07 La directiva script-src de la política de REQ-74-03 SHALL conservar exactamente los orígenes 'self' 'unsafe-inline' https://static.cloudflareinsights.com sin data: ni 'unsafe-eval'.
REQ-74-08 La verificación real con Chrome headless y CDP SHALL registrar en progress/impl_74.md las violaciones de CSP de cada paso de navegación con la política de REQ-64-11 y con la de REQ-74-03.
REQ-74-09 WHEN se implemente la enmienda, los tests que verifican el valor de REQ-74-03 SHALL observarse en rojo antes de modificar src/domain/http/security-headers.ts y public/_headers, WHERE el ciclo test-first de AGENTS.md §3 exige el rojo previo.
REQ-74-10 La política de REQ-74-03 SHALL limitar la fuente data: a las directivas img-src y script-src-elem.
REQ-74-11 WHEN el test evalúa como elemento script la URL del beacon https://static.cloudflareinsights.com/beacon.min.js/v4bc70e2c01a94c73b74392e4234840661791215815920, el test SHALL clasificarla como permitida por script-src-elem.
REQ-74-12 WHEN las constantes CSP de tests/csp-enforce.test.mjs y tests/security-headers.test.mjs y tests/csp-router-inline-script.test.mjs citan el valor de REQ-64-11, cada test SHALL actualizarse al valor de REQ-74-03 con una nota de ajuste que cite el precedente REQ-43-06.
REQ-74-13 WHEN el test de build de REQ-64-05 clasifica el src de un elemento script, el test SHALL usar la directiva script-src-elem y rechazar las URL data: en los HTML del build.
REQ-74-14 WHEN el humano verifica producción tras el deploy de la política de REQ-74-03 con Chrome headless y CDP repitiendo la navegación de REQ-74-05, el navegador SHALL registrar cero violaciones de CSP y la respuesta 200 del script beacon.min.js de https://static.cloudflareinsights.com.
REQ-74-15 La suite completa del arnés y ./init.sh SHALL terminar en verde al cierre con astro.config.mjs y security-headers.ts y public/_headers y cada test tocado dentro de 100 líneas.
