Equivalente al script `pnpm generate-types` (package.json: `wrangler types`).

`pnpm generate-types` → idéntico.

## 4. Forma del archivo generado

- Ruta: `worker-configuration.d.ts` (raíz del proyecto).
- Tamaño: 551.093 bytes (551 KB), 1 línea de cabecera + contracto Env + runtime
  types completos de workerd@1.20260804.1.
- Cabecera: `// Generated by Wrangler by running \`wrangler types\` (hash: ...)`
  y `// Runtime types generated with workerd@1.20260804.1 2026-08-11
  global_fetch_strictly_public,nodejs_compat`.
- Contrato del proyecto: `interface __BaseEnv_Env { ASSETS: Fetcher;
  HTB_API_TOKEN: string; IN_MAINTENANCE: string; HTB_USER_ID: string; }`,
  `declare namespace Cloudflare { interface Env ... }`, `interface Env ...` y
  `NodeJS.ProcessEnv` con las envs `Pick<Cloudflare.Env, ...>` — el runtime del
  worker que consume `cloudflare:workers` en el adapter.
- Idempotencia: el test REQ-30-04 regenera el archivo y verifica byte a byte
  que el contenido NO cambia (pasó en verde). El hash de cabecera es estable.
