# Cómo generar una clave privada Ed25519 en una sola línea con Node.js

Cuando trabajamos con autenticación, firmas digitales o JWTs en servicios web, a menudo necesitamos generar un par de llaves asimétricas de forma rápida y segura. Aunque existen herramientas como OpenSSL en la terminal, a veces estamos en un entorno donde solo tenemos acceso a Node.js o queremos incluir la generación dentro de un pipeline automatizado.

En este artículo veremos un pequeño script en Node.js que genera una clave privada **Ed25519** en formato **PKCS#8 PEM**, la aplana en una sola línea y la deja lista para usar en un archivo `.env` o variable de entorno.

## El comando en una sola línea

Este es el comando completo que puedes ejecutar directamente en tu terminal:

```bash
node -e "const {generateKeyPairSync}=require('crypto');console.log(generateKeyPairSync('ed25519').privateKey.export({type:'pkcs8',format:'pem'}).toString().replace(/\n/g,'\\\\n'))"
```

## ¿Para qué sirve este script?

1. **Generación rápida de secretos:** Permite crear una llave privada criptográfica moderna sin instalar herramientas adicionales.

2. **Formato apto para `.env`:** Las llaves privadas en formato PEM contienen múltiples líneas de texto. Este script convierte los saltos de línea en la cadena literal `\n`, facilitando su copia e inyección en archivos de configuración sin romper el formato.

3. **Seguridad local:** A diferencia de las páginas web que generan llaves en línea, este código se ejecuta 100% en tu máquina, garantizando que nadie más tenga acceso a tu llave privada.

## Explicación paso a paso (Línea por línea / Bloque por bloque)

Desglosemos el fragmento de código JavaScript que se ejecuta dentro del comando:

```javascript
const { generateKeyPairSync } = require('crypto');
```

* **¿Qué hace?** Importa la función `generateKeyPairSync` del módulo nativo `crypto` de Node.js.

* **Detalle:** Usamos la versión síncrona (`Sync`) porque estamos en un script de ejecución rápida de una sola línea donde no necesitamos asincronía.

```javascript
generateKeyPairSync('ed25519')
```

* **¿Qué hace?** Genera un nuevo par de llaves (pública y privada) utilizando el algoritmo **Ed25519**.

* **Detalle:** Ed25519 es un algoritmo de firma digital basado en curvas elípticas (Edwards-curve Digital Signature Algorithm). Es ampliamente recomendado en la actualidad por ser extremadamente rápido, seguro y ofrecer claves de tamaño muy reducido.

```javascript
.privateKey
```

* **¿Qué hace?** Accede a la propiedad de la llave privada dentro del objeto devuelto por la función anterior.

```javascript
.export({ type: 'pkcs8', format: 'pem' })
```

* **¿Qué hace?** Serializa la llave privada a una representación de texto estandarizada.

* **Detalle:**

  * `type: 'pkcs8'`: Especifica el estándar PKCS#8, que es la norma moderna para almacenar claves privadas.

  * `format: 'pem'`: Codifica la información en formato Base64 delimitado por cabeceras legibles (`-----BEGIN PRIVATE KEY-----`).

```javascript
.toString()
```

* **¿Qué hace?** Convierte el `Buffer` binario devuelto por la exportación en una cadena de texto UTF-8 estándar.

```javascript
.replace(/\n/g, '\\\\n')
```

* **¿Qué hace?** Busca todos los saltos de línea (`\n`) de la llave y los reemplaza por la secuencia textual `\n`.

* **Detalle:** Esto evita que al pegar la llave en un archivo de variables de entorno (`.env`) o en la configuración de un proveedor cloud (como Vercel, AWS o Heroku) el texto se interprete como múltiples líneas y cause errores de sintaxis.

```javascript
console.log(...)
```

* **¿Qué hace?** Imprime la cadena resultante directamente en la salida estándar de tu terminal para que puedas copiarla.

## Conclusión

Este pequeño *one-liner* es una excelente herramienta para tu kit de desarrollo. Te permite generar secretos robustos rápidamente manteniendo las mejores prácticas de seguridad al no depender de servidores o páginas web de terceros.
